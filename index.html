Cellarium

Alle Wine- und Proton-Prefixe auf einen Blick: welcher Launcher sie benutzt, was darin installiert ist, wie groß sie sind – und welche nur noch Platz verschwenden.

Live-Demo öffnen Installieren Quellcode
Demo mit erfundenen Daten – klick auf eine Karte

Schluss mit Prefix-Chaos

Jeder Launcher kennt nur seine eigenen Prefixe. Cellarium sucht sie alle zusammen.

Findet alles

Durchsucht das Home-Verzeichnis und fragt Steam, Lutris, Faugus, Heroic und Bottles, wem welcher Prefix gehört.

Zeigt, was drin ist

Installierte Programme direkt aus der Registry des Prefixes, dazu winetricks-Verben, Proton-Version und Architektur.

Entlarvt Überbleibsel

Prefixe ohne Launcher, doppelt installierte Programme und Prefixe, die in anderen Prefixen stecken – mit Größe.

Die üblichen Handgriffe

winecfg, winetricks, Registry, Deinstallieren, eine .exe starten oder den Ordner öffnen – ein Klick pro Prefix.

Der richtige Runner

Proton-Prefixe öffnet Cellarium über umu mit genau dem Proton, das sie angelegt hat – nie versehentlich mit System-Wine.

Sicher aufräumen

Löschen heißt Papierkorb, nur nach Eintippen des Namens und nie, solange im Prefix noch etwas läuft.

Installieren

Nur Python 3.10+ – keine weiteren Abhängigkeiten, kein root.

# holen und installieren
git clone https://github.com/gamunex/cellarium.git
cd cellarium && ./install.sh

# starten (oder über das Startmenü)
cellarium

# aktualisieren
git pull && ./install.sh
  • Läuft lokal: ein kleiner Server auf 127.0.0.1, die Oberfläche öffnet sich als App-Fenster in einem Chromium-Browser.
  • Nur Lesen beim Scannen: Prefixe werden nicht verändert, bis du eine Aktion auslöst.
  • Eigene Namen und Notizen pro Prefix, Prefixe ausblenden, Runner von Hand wählen.
  • Einstellungen in ~/.config/cellarium/config.json – dort lassen sich Suchpfade und Ausnahmen setzen.
